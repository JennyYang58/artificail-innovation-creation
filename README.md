# artificail-innovation-creation
for AIIC class
week 1 creation via deepseek

prompt
帮我做一个"羊了个羊"消除小游戏，具体要求如下：

【核心玩法】
1. 游戏区随机堆叠多层图案卡片，上层卡片会遮挡下层卡片
2. 只有未被遮挡的卡片才能点击，被遮挡的卡片变暗且不可点击
3. 点击卡片后，卡片飞入底部的槽位栏（共 7 个格子）
4. 槽位中凑满 3 张相同图案的卡片时自动消除，并增加分数
5. 槽位被占满 7 张且无法消除时，游戏失败
6. 场上所有卡片都消除完时，游戏胜利

【卡片生成规则】
1. 图案用 emoji 表示，比如 🐑 🌿 🥕 🍎 🌻 🪵 🧶 🍄
2. 每种图案的卡片总数必须是 3 的倍数，保证一定能消除完
3. 卡片分成若干层堆叠，每层有随机的位置偏移，形成遮挡关系
4. 第一关：约 60 张卡片、3 层；之后每关卡片数量和层数递增

【交互细节】
1. 点击卡片有缩放反馈，卡片飞向槽位时有移动动画
2. 三消时槽位里的卡片有缩放消失动画
3. 卡片进入槽位后，自动按图案分组排列（相同图案挨在一起）
4. 加分时有飘字效果

【道具系统】
1. 洗牌：重新随机分配场上剩余卡片的图案，位置不变
2. 撤销：把槽位里最后一张卡片退回原来的位置
3. 移出：把槽位最左边的 3 张卡片移到暂存区
4. 每个道具每关限用 1 次，用完后按钮变灰

【界面要求】
1. 顶部信息栏：当前关卡 / 剩余卡片数 / 分数
2. 中间：卡片堆叠区
3. 底部：7 个槽位格子 + 3 个道具按钮
4. 配色走自然清新风（米白、浅绿、木色），圆角 12px，柔和阴影
5. 要有开始界面和"再来一局"按钮
6. 失败/胜利时弹出遮罩层提示结果

【技术要求】
1. 用单个 HTML 文件实现，HTML + CSS + 原生 JS，不要任何外部依赖
2. 用 emoji 代替图片素材，不需要加载任何资源文件
3. 用绝对定位实现卡片的层叠效果，用 z-index 控制遮挡层级
4. 游戏逻辑和渲染分离，代码要加中文注释
5. 适配手机屏幕，点击区域要够大
