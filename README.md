# 羊了个羊 · 拾荒远征 🐑🏕️

> **在线畅玩**：<https://jennyyang58.github.io/artificail-innovation-creation/>

一个纯原生单文件网页三消游戏。在经典「羊了个羊」玩法之上，融合了 **Roguelite 局内构筑、资源三角、轻策略与模拟经营**——消除依然是绝对核心，其他系统改变的是"你的选择空间"，而不是数值碾压。

## 🎮 玩法

狼群夜袭牧场，村子断了粮。你带领一支**拾荒小队**深入遗迹与矿洞：

- 点击**未被遮挡**的卡片放进槽位，凑齐 **3 张相同图案**即可消除
- 槽位满 **7 张**（可被被动加到 8）就会被击退
- **不同图案产出不同资源**：🌾食物 / ⛏️材料 / ✨符文
- 每关出发前**三选一**一项被动；回村交付订单、升级建设，走得更远

## ✨ 特性

### 🃏 局内构筑（Roguelite 三选一）
每关出发前从 3 项被动里挑 1 项，只在本关生效：

| 被动 | 效果 |
|------|------|
| 🌊 连击心流 | 连击倍率最低 ×2 起步 |
| 🃏 万能符文 | 随机一种图案可当万能牌补位 |
| ↩️ 老练之手 | 撤销道具可用 2 次 |
| 🧺 宽宏槽位 | 槽位 +1，代价得分 ×0.8 |
| 🌾 丰收之手 | 每次消除额外 +1 资源 |
| 🦉 猫头鹰之眼 | 开局透视 4 秒 |

### 📦 资源三角与订单
消除产出资源并存入**仓库**（谷仓决定上限，满了会溢出损失）。村庄订单要求不同组合的资源，交付得**金币与声望**——想高效完成订单，就要在出发前想清楚"这关带谁去"。

### 🧑‍🌾 随行伙伴与天气
- **农夫老约 / 矿工阿镐 / 学徒小符**：各自让对应类别的图案明显更多，出征前选一人随行
- **天气**：☀️晴朗照常 / 🌧️雨天食物+1 但连击窗口 -1 秒 / 🏕️集市日报酬 ×1.5

### 🏡 模拟经营（只影响下一局的选项与上限）
回村结算 → 交付订单赚金币 → **升级谷仓**（资源上限）、**升级工坊**（伙伴偏好加成）、**客栈雇佣伙伴**、购买 🦉透视符 / 🧿撤回符（槽满时自动救你一次）。没有"氪金变强就稳过"，只有更多策略选项。

### 🗺️ 章节地图
每 5 关一章：**青青牧场 → 迷雾森林遗迹 → 雪山矿洞 → 月光地下城**，各有专属图案池与配色主题，走完循环、难度持续增长（60 → 180 张，3 → 6 层）。

### ⚡ 连击计分
5 秒内连续消除分数翻倍：**+30 → +60 → +120 → +240（封顶）**，槽位上方有连击倒计时条。

### 💾 存档
localStorage 自动保存：关卡进度、最高分、资源、金币、声望、村庄建设、道具与伙伴——刷新、关机都不丢。

## 🛠️ 技术

单文件 `index.html`（HTML + CSS + 原生 JS，约 1900 行），零依赖零构建：

- 卡片 DOM 统一放在 `#card-layer`，`transform` 定位实现飞行动画
- 矩形重叠面积判定遮挡；关卡保证每种图案数量为 3 的倍数（必定可解）
- 伙伴偏好通过把更多"三连组"分配给对应类别实现
- 主题切换：`body[data-chapter]` 驱动 CSS 变量
